# Universal HTTP URL Nuller for Binaries

**Universal HTTP URL Nuller** — это консольная утилита для безопасной модификации бинарных файлов (исполняемых файлов `.exe`, библиотек `.dll` и др.). Утилита автоматически находит все URL-адреса, начинающиеся с `http://` и `https://`, и заменяет их на нулевые байты (`0x00`), сохраняя оригинальную длину строк и структуру бинарника.

Инструмент поддерживает гибкую настройку исключений, создание резервных копий и тестовый запуск без изменения файлов.

---

## 🚀 Основные возможности

- **Пакетная обработка:** Возможность передавать несколько файлов или использовать шаблоны (например, `*.exe`, `*.dll`).
- **Безопасность данных:** Автоматическое создание бэкапов с расширением `.bak` перед изменением оригинала.
- **Гибкая система исключений:** Пропуск определенных доменов или полных URL через аргументы командной строки или текстовые файлы.
- **Тестовый режим (`--dry-run`):** Просмотр найденных URL и планируемых изменений без фактической записи на диск.
- **Поддержка кастомного вывода (`-o` / `--output`):** Возможность сохранить результат в отдельный файл.

## 🛠 Установка

Скрипт написан на **Python 3** и не требует установки сторонних зависимостей (используются только стандартные библиотеки).

1. Клонируйте репозиторий или скачайте файл `null_urls.py`:
   ```bash
   git clone https://github.com/your-username/http-url-nuller.git
   cd http-url-nuller
   ```
2. Убедитесь, что у вас установлен Python версии 3.6+:
   ```bash
   python --version
   ```

## 💻 Использование

```bash
python null_urls.py <файлы> [опции]
```

### Доступные параметры

| Флаг | Описание |
| :--- | :--- |
| `files` | Один или несколько файлов для обработки (поддерживаются маски `*.exe`). |
| `-e`, `--exclude` | Домен или URL для добавления в список исключений (можно использовать несколько раз). |
| `--exclude-file` | Путь к текстовому файлу со списком исключений (по одному URL/домену на строку). |
| `-o`, `--output` | Задать имя выходного файла (применяется, если обрабатывается один файл). |
| `--dry-run` | Запустить в режиме проверки: выводит найденные адреса без внесения изменений. |
| `--no-backup` | Отключить автоматическое создание `.bak` файлов. |
| `-h`, `--help` | Показать справку по использованию программы. |

## 📋 Примеры использования

### 1. Простая обработка одного или нескольких файлов
Заменяет URL-адреса в указанных файлах. Для каждого файла создается бэкап (например, `file1.exe.bak`).

```bash
python null_urls.py file1.exe file2.dll
```

---

### 2. Использование исключений через аргументы
Заменяет все адреса, кроме тех, которые содержат указанные домены.

```bash
python null_urls.py *.exe --exclude "a11.gdl.easebar.com" --exclude "cdn.example.com"
```

---

### 3. Использование файла исключений
Вы можете вынести список защищаемых доменов в отдельный файл (например, `excludes.txt`).

**Формат `excludes.txt`:**
```text
a11.gdl.easebar.com
cdn.example.com
https://critical-api.domain.com/v1/
```

**Команда:**
```bash
python null_urls.py *.exe --exclude-file excludes.txt
```

---

### 4. Тестовый запуск с сохранением в новый файл
Позволяет проверить, какие URL будут заменены, и сохранить пропатченный файл отдельно без перезаписи оригинала.

```bash
python null_urls.py MuMuNxMain.exe -o patched.exe --dry-run
```

## ⚙️ Как это работает

1. **Поиск:** Утилита сканирует бинарный файл в поисках последовательностей байтов, соответствующих шаблонам `http://` и `https://`, продолжающихся до первого управляющего символа или нулевого байта.
2. **Фильтрация:** Найденные строки сверяются со списком исключений (переданных через `--exclude` и `--exclude-file`).
3. **Замена:** Каждая подходящая строка полностью заменяется нулями (`0x00`). 
   * *Пример:* Строка `https://example.com/api` (23 байта) превращается в 23 нулевых байта `\x00\x00...`. Это гарантирует, что размер и структура исполняемого файла останутся неизменными.
4. **Сохранение:** Оригинальный файл переименовывается в `.bak`, а измененные данные записываются на его место (или в файл, указанный через `-o`).

---

## ⚠️ Важное примечание

Хотя утилита аккуратно работает со строками и не меняет смещения в бинарнике, замена важных системных URL или адресов загрузки ресурсов может привести к изменению поведения программы или ее аварийному завершению. 

Всегда используйте флаг `--dry-run` перед первой обработкой и проверяйте работу пропатченных файлов.
